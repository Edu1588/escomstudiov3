# Motion MCP

Quando você for instruído a criar interfaces com alta carga de animações (Motion Design) e a utilizar a skill do Motion, você deve utilizar o servidor MCP disponível em `https://mcp.motion.so/mcp` (se configurado no seu ambiente) para gerar ou consultar referências de vídeo e animação da Mosaic/Motion.

## Regras de Uso:
1. Sempre verifique se o servidor `motion` está disponível na sua lista de MCPs.
2. Utilize as ferramentas do servidor para auxiliar na codificação de animações web.
3. Caso o servidor não seja acessível via ferramentas diretas, aplique as melhores práticas de Motion Design (como GSAP, Lenis e Curvas Cúbicas) ao desenvolver componentes visuais premium.
