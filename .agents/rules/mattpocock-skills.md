# Real Engineering Skills (Matt Pocock)

Sempre que o usuário enviar um novo pedido ou comando, acione as diretrizes e ferramentas do pacote de skills do Matt Pocock instalado no projeto (`.agents/skills/`):

- Para novas features: acionar `implement` e `tdd`.
- Para refatorações: acionar `improve-codebase-architecture` e `codebase-design`.
- Para bugs: acionar `diagnosing-bugs`.
- Para navegação/investigação: acionar `wayfinder`.
- Para code review: acionar `code-review`.
